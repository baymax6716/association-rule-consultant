# Association Rule Consultant Skill

A GitHub-distributable Codex Skill for association-rule-based statistical consultation.

The installable Skill is in [association-rule-consultant](association-rule-consultant/). Its own [README](association-rule-consultant/README.md) explains installation, scope, and the presentation-ready design rationale.

## Quick use

Copy `association-rule-consultant/` into `~/.codex/skills/`, then invoke:

```text
Use $association-rule-consultant to analyze my dataset for a decision question.
```
